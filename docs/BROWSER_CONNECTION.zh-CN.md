# 可选网页积分连接

[English](BROWSER_CONNECTION.md) · [首次使用](GETTING_STARTED.zh-CN.md)

0.4.3 支持 TapNow 和 Ideogram，浏览器组件默认关闭。2026-11-02 核对到的 TapNow MCP 工具目录没有余额查询方法；连接 MCP 本身并不能提供积分。官方说明：[自定义连接器](https://docs.tapnow.ai/en/docs/mcp/add-a-custom-connector)。

## 连接自己的浏览器

1. 刻度中打开 **全部工具 → TapNow / Ideogram → 查看 → 连接网页余额**。
2. 打开组件文件夹，在 Chrome / Edge 的扩展管理页加载已解压的组件。这不是商店扩展。升级刻度后，在扩展管理页重新加载一次现有组件，原配对和网站授权继续使用。
3. 刻度点击 **开启并复制配对码**，在浏览器的刻度扩展中粘贴并连接。配对码仅用于本机连接，请勿分享。
4. 选择平台并点击打开按钮，授权该网站。通过平台原有页面登录，刻度没有额外登录表单。
5. **TapNow：** 正常打开已经登录的主页即可；无需从组件另开专用页，也不用一直开着。组件短暂打开固定账户菜单，稳定采样余额和当前团队标识后恢复菜单。如果你正在操作菜单，本次读取让位，不强行关闭菜单。**Ideogram：** 仍使用组件打开的专用页，点选完整余额和长期可见的账户/团队标识，Esc 取消。
6. 有效读数显示金额、读取时间以及“网页显示 · 账号待核实”。有效的零余额保留为已用尽；读不到不会变成零。

## 按需同步与恢复

- TapNow 主页打开完成或切回时会请求读取，活动触发至少间隔 30 秒；暂停自动查询时不触发。保持主页打开期间，原有五分钟采样继续运行。
- TapNow **不重新加载网页、不自动打开后台页、不保活、不唤醒休眠标签页**。组件只查询已经获准的 TapNow 域名，不读取其他网站。
- 仅支持 `https://app.tapnow.ai/home` 的正常主页。画布、登录页、带查询参数或片段的页面不读取；不会跳离你正在创作的画布。
- 用完可直接关闭网页或浏览器。额度中心保留上次积分与时间，标明待确认；小仪表背面沿用只显示有效读数的规则。再次打开主页后恢复读取，不需要重新配对。
- 同时打开多个主页时，优先当前活动主页，再按最近使用排序；每次只采样一个。团队变化会丢弃不稳定读数，下一次稳定读数仍标记账号待核实。
- **立即读取**可在暂停自动查询时手动使用。休眠暂停读取，退出登录或布局变化保持待确认。网页显示可能尚未反映服务端最新变动，读取时间仅表示页面观察时间。
- Ideogram 保留专用页定时刷新方式。浏览器重启后需要重新打开其专用页，已选位置保留。

目前没有接入 TapNow 客户端余额来源，也没有可用的 MCP 积分适配器。未来接口必须先核对只读语义、返回字段与账户范围，再实现适配；不会按工具名字猜测并执行新工具。本次没有新增后台监控任务。

## 会读取和保存什么

- 权限仍为定时唤醒、组件本地存储、脚本注入及本机桥接。TapNow / Ideogram 网站权限分别可选，没有新增全站、Cookie、历史、调试器或请求拦截权限。
- 仅读取固定可见 TapNow 余额/团队字段，或本人选定的 Ideogram 余额/账户字段。不读取密码、网页存储、隐藏状态或复制登录会话。
- 组件本地保存配对密钥和点选位置；刻度在当前用户目录加密保存配对密钥，并保存积分观察记录。通信限制在本机固定消息，没有任意网址或脚本执行入口。
- 重新配对撤销旧密钥；关闭网页连接停止本机监听。卸载组件不删除积分历史。
- 网页读数不验证账户归属、不提取日期、不产生积分到账证明。未验证账号的观察不会绑定到已验证账号日期。

验证：已有 0.4.2 Windows 真实余额及二十分钟后台采样证据。0.4.3 新的普通主页发现、关闭/休眠停止、无页面刷新、活动限频、菜单恢复与暂停行为已通过隔离回归测试；新流程的真实浏览器验证需加载新版组件后完成，不能套用旧版证据。Ideogram 与 Mac 仍待现场验证。
