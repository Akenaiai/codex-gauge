# 可选的网页余额连接

[English](BROWSER_CONNECTION.md) · [首次使用](GETTING_STARTED.zh-CN.md)

0.4.2 支持 TapNow 和 Ideogram，使用可选的 Chrome / Edge 组件，默认关闭。2026 年 11 月 1 日核对这两个平台的官方会员 MCP 工具清单，均未发现余额查询工具，因此仅完成 MCP 授权还不能在刻度里看到积分。

## 连接自己的浏览器

1. 在刻度打开 **全部工具 → TapNow（或 Ideogram）→ 查看 → 连接网页余额**。
2. 点击 **打开组件文件夹**，再点 **Chrome 扩展管理** 或 **Edge 扩展管理**。在浏览器扩展管理页启用 **开发者模式**，选择 **加载已解压的扩展**，选中刚打开的文件夹。这是本地加载的组件，尚未上架浏览器商店。保留该文件夹；升级刻度后，在扩展管理页重新加载组件。
3. 在刻度点击 **开启并复制配对码**。打开浏览器中的刻度扩展图标，粘贴并点 **连接本机刻度**。配对码是本机连接密钥，请勿发给他人。
4. 选择平台并点击 **打开专用网页**，浏览器会单独请求这个平台的访问权限。需要登录时，在平台原来的浏览器网页完成，刻度没有账号登录框。
5. **TapNow：** 在专用主页登录后，组件会自动打开固定的账户菜单，读取余额行和主页上的当前团队标识，无需点选位置。读取期间团队变化会丢弃本次结果；不读取菜单中的其他账号字段。**Ideogram：** 显示完整的余额和长期可见的账户 / 团队标识，再点击 **点选余额与账户标识**，依次点选；按 Esc 可取消。价格、`1.2k` 缩写、`10 / 100` 组合值不作为有效余额。
6. 回到刻度。成功后显示余额、读取时间和 **网页显示 · 账号待核实**。确实读到零会保留为“已用尽”，缺失或不支持的读数保持待确认。

账户 / 团队标识用于发现选定位置或账户变化，不验证账号归属。如果页面无法同时保持两个位置可见，就无法完成自动读取，可继续在额度中心保存独立的本人记录。网页读数不能绑定已验证账号的日期，也不确认积分已经发放到账。

## 自动刷新与恢复

刻度运行且开启自动查询时，每五分钟请求一次读数。组件轮询本机连接，只刷新它自己创建的专用标签页并读取 TapNow 固定字段或 Ideogram 选定位置。请保持浏览器运行、专用标签页停留在受支持的主页。其他工作标签页不会被刷新。关闭标签页、退出登录、页面位置改变或读取失败时，余额转为待确认，未知不会变成零。

**立即读取** 是手动查询，暂停自动查询时仍可主动使用；电脑睡眠时停止读取。重启浏览器或重新加载组件后，需要再次点 **打开专用网页**，Ideogram 选定位置保存在本机。重启刻度后，历史网页余额会先保持离线，等新读数到达。更换账户 / 团队后请自行核对；TapNow 在后续稳定读数中使用当前团队，Ideogram 可能需要重新点选，两者都不验证账号归属。

在刻度点 **重新配对** 可让旧连接失效并生成新码；**关闭网页连接** 会停止本机监听。移除浏览器组件不会删除刻度历史记录。当前桌面验证环境是 Windows，Mac 浏览器连接尚未实机验证。

## 会读取和保存什么

- 浏览器权限包括定时器、扩展本地存储、页面脚本和 `127.0.0.1` 本机连接。TapNow、Ideogram 的访问权限分开请求，均为可选；不申请 Cookie、调试器、浏览历史或请求拦截权限。
- 网页读取仅限专用页面的可见余额、账户 / 团队标识：TapNow 用固定位置，Ideogram 由本人点选。不读取输入框、可编辑内容或隐藏页面状态，不向刻度复制密码、Cookie、网页存储或登录会话。
- 组件在本机保存配对密钥和 Ideogram 选定的页面位置；刻度保存经过系统加密的配对密钥，以及包含网页账户 / 团队标识的当前用户余额记录。本机连接默认不开启，启用后校验固定扩展来源和认证消息，只接受固定的读取请求，不提供任意网址或脚本执行入口。
- 不向刻度服务器发送网页余额或账户标识。正常刷新网页仍会访问平台，平台可以感知这些访问。授予网站权限意味着允许组件访问该网站，可审查开源代码并只授权自己需要的平台。

组件及本机连接已做自动检查和隔离原生应用验证。真实平台仍需用户在自己的浏览器加载组件、授予网站权限并成功读取，Ideogram 还需选定位置，这些不由模拟测试证明。到期和每月发放日期继续保留各自来源；该组件目前只读余额，不抓取网页日期、不自动生成日期规则。

Windows 现场验证：真实 TapNow 网页余额已传入安装版，并与创作背面一致；完整五分钟观察窗口内读数自动更新，执行者未手动触发刷新。这不验证账号归属或日期，也不代表 Ideogram 和 Mac 已实测。

0.4.2 后台补验：Windows 连续 20 分钟完成 4 次自动读数，期间未自动操作浏览器或由执行者手动刷新，全部心跳采样在线。采样放在组件后台，页面执行同步短读；读取、点选都有期限并核对预期主页。超时保持待确认，后续周期可重试。这是当前 Windows 环境的现场证据，不代表所有浏览器或账号归属均已验证。
