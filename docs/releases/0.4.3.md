# 0.4.3 — TapNow on-demand sync

TapNow now discovers normally opened, permitted home tabs. Opening or returning to the home page requests a read; existing five-minute sampling continues while it is open. Gauge no longer reloads TapNow, opens a separate background tab or wakes discarded pages. Close the page after use; the credit center retains the last amount and time as unconfirmed.

The account menu is restored after sampling unless the user takes over. Activity requests are throttled and respect automatic-query pause. Existing pairing, site permissions, original Codex gauge and Ideogram behavior are preserved. Reload the existing browser extension once after updating Gauge.

No MCP balance query or desktop-client balance source is available in this version. Page data remains account-unverified and may lag the provider’s server. Only the normal home page is supported, not working canvases. Isolated automated checks cover the new flow; live browser validation awaits the updated extension. Mac and Ideogram remain unverified in the field.

## 简体中文

TapNow 改为识别正常打开的主页，打开或切回时读取，保持打开期间沿用五分钟采样。不会刷新页面、另开后台页或唤醒休眠页。用完直接关闭，额度中心保留上次金额与时间并标记待确认。

读完恢复临时打开的账户菜单，用户操作时让位。活动读取限频并遵从自动查询暂停。原配对、网站权限、Codex 小仪表和 Ideogram 流程保持。升级后需在浏览器扩展管理页重新加载一次原组件。

当前没有 MCP 或客户端积分来源，仅支持正常主页。网页读数不验证账号、也不等于服务端刷新。新流程已完成隔离自动检查；真实浏览器流程须加载新版组件后验证，Mac 和 Ideogram 尚未现场验证。
