# 0.3.4 — Monthly grant forecasts without another sign-in

Gauge continues to use existing local CLI/MCP connections and optional system-encrypted API credentials. This release adds no Gauge account, provider browser-login window, browser-session import or cookie reader. Website date observations remain historical observations; they are not presented as unattended website refreshes.

Named accounts can now forecast monthly grants from a known grant date or a credit-expiry date. The forecast follows the same day each month. Short months clamp to their last day, then restore the original day in later months. Expiry clock text is never inherited as a supposed grant time. Expected grants have a distinct source and remain unconfirmed even when a balance query succeeds.

Details provides a bilingual monthly-rule editor, including disabling forecasts and reminders independently. These choices survive imported observations and restarts. Advance, due-date and bounded overdue verification notices have separate deduplication stages; zero balance does not suppress an expected-grant reminder. Account scopes remain independent, and permanent/purchased/daily pools do not acquire monthly renewal rules.

Validation: 109 automated checks and 33 packaged native-window interaction checks. Existing badge, queries, credentials and preferences are retained. Natural future notifications and macOS retain their prior field-test limits.

## 简体中文

继续使用本机已有 CLI/MCP 连接及可选的系统加密 API 凭据，不新增刻度账号、平台网页登录、浏览器会话导入或 Cookie 读取。网页日期仍是历史核对记录，不冒充网页自动刷新。

新增按每月同日预计发放：可从上次发放日或积分失效日推算。短月取月底，下个月恢复原日号；只预计日期，不继承失效钟表时刻，也不把余额查询成功说成已到账。

详情可修改或关闭月度规则、独立开关提醒，导入与重启后保留。发放前、当日及限定窗口内的过日核实分别去重，零余额也可收到预计发放提醒。规则按账户隔离，永久、充值和每日积分不套用月度规则。

109项自动检查与33项发行资源原生操作。原小仪表、查询、已有凭据和偏好保留，自然未来通知与Mac继续待验。
