# 0.3.14 — Click the card to flip

Click the expanded panel’s content or blank space to flip between Codex usage and creative credits. The existing corner buttons remain available. A fast double click flips once; buttons, links, text selection, dragging and scrolling retain their own behavior. The settings page stays a settings page.

Windows checks cover native pointer clicks in both directions, double clicks, controls, selection, scrolling and the existing creative-credit flows. Mac remains unverified.

## 简体中文

单击展开卡片的内容或空白处，即可在 Codex 额度和创作积分之间翻面，右上角按钮继续保留。快速双击只翻一次；按钮、链接、选中文字、拖动和滚动保留原操作，设置页内点击也保持在设置页。

Windows 已检查双向原生点击、双击、按钮、文字选择、滚动和原有创作积分流程。Mac 尚未实机验证。
