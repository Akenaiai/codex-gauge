# 0.3.6: Flip to creative credits, with Suno MCP

The expanded Codex gauge card now has two faces. **Creative credits** flips to image, video and music quotas; **Flip back** returns to the original Codex gauge. The 52-pixel badge, dragging and double-click reset remain available. The selected face is saved locally; reduced-motion preferences disable the rotation.

The creative face shows available, used-up and unconfirmed states, each provider's remaining amount, read time and available credit dates. Coding windows, research/API cash balances, reset cards and download credits stay outside this preview. A coding service's explicitly identified video entitlement can appear on its own. Dates name their pool and account; a small bonus expiry never implies the entire balance expires. Creative refresh queries media sources without refreshing the original Codex window or research services.

Suno uses the existing enabled Codex MCP connection, calling only `account-me`, `account-usage`, then `account-me` in an ephemeral context. It does not request model responses or generation. Public-handle changes invalidate the observation; because this response lacks a stable account ID, it does not inherit confirmed account-date rules or assert renewed credits. Song-generation credits and download credits are separate, and the overview uses generation credits. `renews_on` stays a subscription billing boundary, not an invented credit-expiry/grant date. No extra login or credential export is introduced.

Windows packages remain unsigned. Mac and naturally occurring future reminders still require field testing.

## 中文

展开原 Codex 小仪表后，点击 **创作积分** 可翻到生图、生视频、生音乐额度，点击 **翻回** 返回原仪表。头像上的52像素小仪表、拖动和双击归位保留。翻面选择保存在本机；系统开启减少动态效果时不播放旋转。

背面区分有积分、已用尽、待确认，展示余量、读取时间和已知积分日期。编程周期、资料查询、API现金余额、重置卡和下载额度不混入；同平台明确的视频权益可单独显示。日期带积分池和账号，赠金到期不会暗示总额全部到期。背面的刷新只查创作来源。

Suno 沿用已有启用的 Codex MCP，只读取账户公开标识与用量，不生成作品、不调用模型、不提取凭据。前后公开标识变化会丢弃读数；因无稳定账户ID，不继承已确认的账号日期，也不宣称已恢复。歌曲生成积分与下载额度分开，总览按生成积分判断；会员续期不当作积分到期或发放日，无需额外登录。

安装包仍未签名；Mac和自然未来通知仍待实测。
