# 0.3.2 — Quotas at a glance

The credit-center home now shows one compact row per queried tool. Four clickable summaries filter **Available**, **Used up**, **Expiring / resetting**, and **Unconfirmed**. Near-term expiries come first, followed by approaching resets. Each row pairs the remaining amount with its state and next known dates; unconnected inventory entries stay in All tools.

Reset-credit expiry is named explicitly, independently of model quota. Unknown or stale readings stay unconfirmed, while missing dates stay unknown. Each provider keeps its own units. Coding-window limits exclude separate video/tool entitlements, known DeepSeek grant/purchased cash balances can be combined within one currency/account, and independent accounts are never added together. Multi-account deadlines identify their account.

Details retain every pool, source, date editor, official rule and encrypted connection action. Query and reminder controls remain accessible at narrow desktop widths. The original Codex badge, existing credentials, automatic queries and notifications are preserved. The interface and example screenshots support Chinese and English; public screenshots use synthetic data.

Validation: 90 automated checks and 21 packaged native-window interaction checks. Windows installation, source correspondence and remote release checks are recorded separately. macOS and naturally occurring future notifications retain their existing field-test limits.
