# 0.4.6: account credit balance in the Codex panel

## English

The duplicate “Available capacity” bar is replaced by a numeric **Credit balance** card, read from the existing official Codex account quota response. Subscription-window percentages, account credits, and reset-credit counts stay separate: a weekly window can show 0% while the credit balance remains positive. No additional connection, credential or paid request is needed.

The main number shows whole credits with grouping; hover reveals fractional precision. A positive balance below one is shown as `<1`, explicit zero as `0`, and missing or invalid data as `—`. An upstream unlimited flag has its own label. Disconnected or old snapshots label the balance as a last reading. Account-switch isolation and the existing badge rings, reminders, reset cards and provider connections are preserved.

Validated with 266 automated checks, seven native UI scenarios covering English/Chinese, dark/light, narrow layouts, unknown/zero/unlimited balances and stale data, plus the Windows packaged and upgrade checks. Public example screenshots, when used, contain synthetic data. Windows binaries remain unsigned; existing macOS and other field-validation limits remain unchanged.

## 简体中文

去掉重复的“可用余量”条，替换为数字形式的**额度余额**，直接读取现有官方 Codex 账号额度接口。套餐周期百分比、额度余额、重置机会分别显示：本周额度为 0% 时，余额仍可为正数。无需新增连接、凭据或付费请求。

主数字显示带千位分隔的整数，悬停可看小数精度。正余额不足 1 时显示 `<1`，明确的零显示 `0`，缺失或无效数据显示 `—`；接口明确返回不限量时单独标注。断线或旧快照会说明是上次余额。账号切换隔离、小图标圆弧、提醒、重置机会和已有平台连接保持。

验证包括 266 项自动检查、七组原生界面场景（中英、明暗、窄窗口、未知/零/不限量及旧读数），以及 Windows 包内和升级检查。公开示例图片使用合成数据。Windows 文件仍未代码签名，Mac 等既有现场验证边界不变。
