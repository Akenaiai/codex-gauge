# 0.4.5-preview.2: quota colors and verified native connections

## English

This Windows preview keeps the existing badge layout and adds battery-style quota colors: the displayed number and its arc turn amber at 20% or less, then red at 10% or less. Each quota window changes independently. Replenishment restores the normal color; missing and stale readings keep their existing meaning. Credit-expiry markers remain separate.

Runway and Recraft independent OAuth were verified on Windows with official authorization, real account/quota reads, a subsequent refresh, and another refresh after installing and restarting Gauge. These new routes work without borrowing another client's tokens. Existing settings, historical record IDs, date rules and browser pairing were preserved during a real upgrade from 0.4.4.

MiniMax's existing Relay reader was checked after the upgrade. The optional international Subscription Key route still lacks a live-key test; its automated error, storage and identity-isolation checks are not a substitute. macOS, a separate clean physical computer, Ideogram live reading and naturally scheduled notifications remain unverified. Stable downloads remain 0.4.4; this is a preview, not a stable promotion. Windows binaries are unsigned.

Verification: 262 automated checks, 35 isolated native-connection UI checks, 14 production-main checks, 23 packaged first-run/legacy-profile checks, and 322 artifact/source/payload comparisons. A restart issue in the acceptance script was fixed: closing the center only hides it, so the script now closes the test application before reusing its profile and limits fallback cleanup to its own child process tree.

The ZIP and installer include both this change and the earlier connection setup. Back up the existing local profile before testing an upgrade. Keep the 0.4.4 installer and the pre-upgrade profile available for rollback; do not copy someone else's profile or authorization files. `SHA256SUMS.txt` and `SOURCE_VERSION.json` bind downloads to the reviewed source, not to code-signing identity.

## 简体中文

本 Windows 预览保留原小仪表布局，加入类似电池的余量颜色：显示余量 ≤20% 时数字与对应圆弧变为琥珀黄，≤10% 时变红。各额度周期独立判断，恢复额度后回到原色；未知与旧读数保持原有含义，重置卡到期标记独立保留。

Runway、Recraft 的独立 OAuth 已在 Windows 完成官方授权、真实账号与额度读取、再次刷新，以及安装重启后的刷新验证。新路径不借用其他客户端的令牌。从 0.4.4 实际升级后，原设置、历史记录 ID、日期规则和浏览器配对均保留。

MiniMax 原 Relay 查询已在升级后验证；可选的国际站 Subscription Key 路径仍缺少真实 Key 实测，自动化的错误、存储与身份隔离检查不能替代它。Mac、另一台干净实体电脑、Ideogram 真实读取及自然未来通知仍待验证。稳定下载保持 0.4.4，本版保持预览身份，不提升为稳定版。Windows 文件未代码签名。

验证包括：262 项自动检查、35 项隔离原生连接界面检查、14 项生产主进程检查、23 项包内首次使用与旧配置检查，以及 322 项产物、源码与安装载荷比对。修复了验收脚本的重启问题：关闭额度中心只是隐藏窗口，现在会先关闭测试应用再复用配置，必要的进程清理只针对脚本自己的子进程树。

ZIP 和安装器包含本次调整及之前的连接引导。体验升级前备份原本机配置；保留 0.4.4 安装器与升级前配置用于回退，不复制他人的配置或授权文件。`SHA256SUMS.txt` 与 `SOURCE_VERSION.json` 绑定下载文件和受检源码，不代表代码签名。
