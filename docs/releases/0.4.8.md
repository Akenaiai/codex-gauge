# Codex Gauge 0.4.8

## English

With 30% or more quota remaining, the weekly Codex reminder starts 24 hours before reset. Both weekly and five-hour windows also have 4h, 2h and 1h stages. Each stage sends one silent notification per account and window when enabled and a fresh reading is available.

The Windows Coding tools panel includes Cursor, Qoder, Devin CLI, Kilo Gateway and supported subscriptions. TapNow supports its official Codex MCP connection. This version includes creative expiry coverage and provider recovery indicators.

For ZCode, open **All tools → Z.AI → Connect Coding Plan key** and enter a personal BigModel China Coding Plan API key. Gauge verifies the quota query before encrypting the key locally. Existing Relay readings become historical. Team plans and the international Z.AI endpoint are outside this connection.

Windows x64 installer and portable ZIP. Windows binaries are unsigned. Mac remains experimental. BigModel key handling and quota parsing were tested with synthetic responses. Live paid-account results and natural Windows notification delivery remain unverified.

## 简体中文

Codex 余量至少 30% 时，周额度从重置前 24 小时开始提醒。周额度和 5 小时额度另有 4、2、1 小时提醒。开启通知后，刻度取得新鲜读数时，每个账户的每个额度周期同一档静默提醒一次。

Windows 编程工具面板包含 Cursor、Qoder、Devin CLI、Kilo Gateway 及支持的订阅。TapNow 可沿用 Codex 中的官方 MCP 连接。本版也包含创作积分到期覆盖提示和平台恢复提示。

ZCode 用户可在**全部工具 → 智谱 / Z.AI → 连接编程套餐密钥**中填写智谱中国站个人编程套餐 API Key。刻度验证额度查询成功后，由本机系统加密保存密钥。旧 Relay 读数保留为历史记录。此连接仅适用于中国站个人编程套餐。

提供 Windows x64 安装包和免安装 ZIP，二进制文件未签名。Mac 仍为实验性支持。智谱密钥处理和额度解析已用模拟响应测试，真实付费账户读数与自然触发的 Windows 通知送达仍待验证。
