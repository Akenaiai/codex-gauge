# 0.3.0 — AI credit center / AI 工具额度中心

Codex Gauge now includes a desktop credit center alongside its existing profile badge. It inventories local CLI, MCP and plugin configuration evidence, shows separate account/source and credit pools, and presents known expiry, renewal and billing dates without conflating them.

Read-only integrations cover Pippit, Dreamina, the original Codex reader, DeepSeek and Firecrawl APIs, plus Kimi/MiniMax/ZCode through the optional installed Agent Relay companion. Host-managed connector readings can be imported with their actual query timestamps. Tools without verified balance access stay visible as inventory entries. Manual readings and confirmed dates are supported.

Expiry and approaching-reset reminders reuse the existing acknowledgement-based delivery and deduplication. Actual renewal needs verified identity and cycle evidence; a user-recorded renewal date reaching its time only asks for verification. The original Codex badge, card reminders and preferences are preserved. Includes a local read-only MCP snapshot sidecar and bilingual documentation.

No automatic spending, generation, card redemption, recharge, account switching or model calls. Unknown dates remain unknown. Natural notification delivery, Mac device behavior and interfaces without readable expiry metadata remain explicit limitations. See [the credit-center guide](../CREDIT_CENTER.md).

中文：在原 Codex 小仪表旁新增额度中心，统一梳理本机 CLI、MCP 与插件，展示各来源余额、到期与恢复日期。已知接口走只读查询，宿主快照与本人记录独立标明；查询失败不当作零余额，账期结束不当作积分到期。支持到期、重置前提醒与有证据的恢复通知，保留原设置和通知机制。程序不会自动消耗额度、生成、充值或用卡；缺失日期及尚未完成的真机/自然通知验收仍明确列出。
