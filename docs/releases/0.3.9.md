# 0.3.9 — Visual refinement

- Refines the compact Codex gauge, expanded coding/creative faces and full credit center with consistent surfaces, clearer readouts, stronger status hierarchy and improved dialogs.
- Keeps the 52px badge footprint, dark/light and Chinese/English support, native positioning, IPC and all credit/date semantics. Includes the daily-credit behavior from 0.3.8.
- Visual implementation assisted by Kimi K3.1 Pro; independently checked with 154 automated tests, 21 isolated native checks and Browser interactions using synthetic data. See [validation and screenshots](../VISUAL_REFRESH.md).

This release does not add native Mac positioning, new account login, automatic quota consumption or media generation. Windows builds remain unsigned.
