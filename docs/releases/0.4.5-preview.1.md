# 0.4.5-preview.1: first-run connections

## English

Windows preview for the new connection flow. Stable downloads and the daily installation remain at 0.4.4. Product name, application ID and configuration format remain unchanged.

Choose platforms, follow their connection instructions, optionally add membership notes, then enter the credit center. You can postpone connections and skip membership notes. Interrupted setup resumes after restarting. Explicitly hidden platforms stay hidden; hiding keeps account references, dates and reminder choices.

Runway and Recraft offer independent official-browser OAuth. MiniMax international accepts a Subscription Key through its subscription reader. These paths run without Codex CLI, Agent Relay or Python. Real new-account OAuth and Subscription Key balances still need owner verification. OAuth permissions are shown before connecting; approve them yourself on the official page. Other providers retain the dependencies documented in [Native connections](../NATIVE_CONNECTIONS.md). API credits, subscriptions and regions are separate. Missing readings stay unknown; historical readings retain their timestamps.

The Windows executable and its packaged production UI are checked with empty tool paths and isolated synthetic profiles. Source regression tests also cover cancellation, failed authorization, account changes and data rollback. Synthetic results do not establish live provider balances or human visual approval. Physical clean-machine installation, macOS, Ideogram field reading and naturally scheduled future notifications remain unverified. Windows files are unsigned.

Download the Windows ZIP from this preview release, extract it into a separate directory and run `Codex Gauge.exe`. It uses the existing application profile by default. To preserve your daily profile, run acceptance with `node scripts/packaged-acceptance.cjs <extracted-exe> <new-evidence-directory>` from a source checkout after `npm ci`. That script creates isolated profiles and exits after checking. Keep stable 0.4.4 available for rollback. Avoid running the preview installer over your daily installation until the remaining owner checks are complete.

SHA256SUMS.txt verifies download integrity; SOURCE_VERSION.json binds artifacts to the source commit. Hashes are not code signing. The receipt records exactly which files and checks were verified.

## 简体中文

本版本是首次连接流程的 Windows 预览。稳定下载和日常安装继续使用 0.4.4。产品名、应用标识和配置格式保持原有身份。

选择平台，按照对应指引连接，可选填写会员备注，然后进入额度中心。连接可稍后处理，会员备注可跳过；中断后重启会继续。明确隐藏的平台跨重启保持隐藏，账号引用、日期和提醒选择继续保留。

Runway、Recraft 提供独立的官方浏览器 OAuth；MiniMax 国际站支持 Subscription Key 订阅读取。这三条路径无需 Codex CLI、Agent Relay 或 Python。本人新授权和 Subscription Key 的实际余额仍待核对。连接前显示授权权限，由本人在官方页面确认。其他平台保留[独立连接说明](../NATIVE_CONNECTIONS.zh-CN.md)中列出的依赖。API、会员订阅和地区分别处理。缺失读数保持未知，历史读数保留时间。

Windows 可执行程序及包内生产界面使用空工具路径、隔离合成配置检查。源码回归另覆盖取消、授权失败、账号变化和数据回退。合成结果不证明平台真实余额或用户视觉认可。实体干净电脑安装、Mac、Ideogram 现场读取及自然未来提醒仍待验证。Windows 文件未进行代码签名。

从本预览 Release 下载 Windows ZIP，解压到单独目录后运行 `Codex Gauge.exe`。默认会使用原应用配置。如需保护日常配置，可在源码目录执行 `npm ci` 后运行 `node scripts/packaged-acceptance.cjs <解压后的exe> <新证据目录>`，脚本使用隔离配置并在检查后退出。保留稳定版 0.4.4 供回退。本人剩余检查完成前，请保留日常安装。

SHA256SUMS.txt 用于下载完整性校验；SOURCE_VERSION.json 绑定产物与源码提交。哈希不代表代码签名。回执按实际范围记录文件和检查结果。
