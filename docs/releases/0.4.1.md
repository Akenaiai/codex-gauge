# 0.4.1 — TapNow account-menu balance

**Follow-up preview notice:** an extended background session stopped reporting after the initial automatic-refresh check. Those background-read and heartbeat issues are corrected in the follow-up version. This preview is superseded by [0.4.2](0.4.2.md), which includes the bounded background reader and longer field verification.

TapNow no longer needs two point selections. In the paired browser component, choose TapNow and open its dedicated home page. The reader opens only the fixed account menu, reads the balance row and checks the visible current-team marker. It reopens that menu after each scheduled page refresh. A team change during a read discards that observation. Ideogram retains its selected-field reader. No additional browser permissions are introduced.

The previous generic parser rejected TapNow's complete labelled balance text, and reloading the page closed its balance dialog. The fixed TapNow reader avoids dependence on that temporary dialog; the generic parser also accepts explicit Tapies balance labels while continuing to reject rates, prices, abbreviated amounts and mixed counters.

Installed unpacked components must be **reloaded in Chrome/Edge's extension manager after upgrading Gauge**, then use **Open dedicated tab** again. Pairing stays local; no provider login is added inside Gauge. Browser observations remain account-unverified and do not establish grant arrival or credit expiry.

197 automated checks, 73 packaged native fixture checks and 18 installer-ASAR synthetic-user isolation checks pass. A real TapNow balance reached the installed Windows app and matched its creative back; a full five-minute observation confirmed automatic updates without an agent-triggered manual refresh. The upgrade preserved existing pairing, preferences and independent dates. Ideogram and Mac remain without live field validation.

## 简体中文

**后续预览说明：** 初次自动刷新检查通过后，更长时间的后台运行出现停止上报。读取期限和独立心跳已在 [0.4.2](0.4.2.md) 修复，并补做更长时间后台验证；此预览已被后续版本替代。

TapNow 不再需要点选两个位置。在已配对的浏览器组件里选择 TapNow 并打开专用主页，组件会打开固定账户菜单，读取余额行和当前团队标识；每轮网页刷新后重新打开菜单。读取期间换团队会丢弃本次结果。Ideogram 保留原点选方式，不增加浏览器权限。

旧通用解析器不接受带完整 Tapies 余额标签的文字，网页刷新还会关闭原余额弹窗。TapNow 专用读取流程不再依赖临时弹窗；通用解析器也支持明确的 Tapies 余额标签，继续拒绝汇率、价格、缩写和组合计数。

更新刻度后，需要在 Chrome / Edge 扩展管理页**重新加载组件**，再点 **打开专用网页**。配对留在本机，不在刻度内登录平台。网页余额仍标记账号待核实，不证明发放到账，不推断积分到期日。

197 项自动检查、73 项包内原生模拟检查、18 项安装器实际代码的合成用户隔离检查通过。真实 TapNow 余额已传入 Windows 安装版并与背面一致，完整五分钟观察确认读数自动更新，执行者未手动触发刷新。升级保留原配对、设置和独立日期。Ideogram 与 Mac 仍待真实现场验证。
