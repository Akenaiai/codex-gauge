# 0.4.5: Windows stable — connections and low-quota colors

## English

This stable Windows release promotes the functionality verified in 0.4.5-preview.2. Runtime behavior is unchanged; the version and current release documentation are updated.

- The existing badge keeps its size and layout. Its number and matching arc turn amber at a displayed 20% remaining or less, then red at 10% or less. Each window is independent and returns to its normal color after replenishment.
- First-run setup guides platform selection and connections, allows optional membership notes, resumes interrupted setup, and preserves explicitly hidden platforms.
- Runway and Recraft support their own official-browser OAuth; MiniMax international supports Subscription Key quota reads. All three were verified with real read-only responses, local encrypted persistence, and refresh after restarting the installed Windows app. They do not require Codex CLI, Agent Relay or Python. Other providers retain their documented dependencies.
- Existing settings, historical record IDs, dates and browser pairing survive the upgrade. Credentials and account data stay outside the distribution. MiniMax key binding does not establish a verified personal or team identity.

Validation includes 262 automated checks, isolated production UI/main checks, packaged first-run and legacy-profile checks, artifact/source comparisons, and a real Windows upgrade. Download the setup executable or portable ZIP from this release; check `SHA256SUMS.txt` and `SOURCE_VERSION.json` for artifact integrity and source provenance. Keep the previous installer and a local profile backup for rollback.

Stable support here means the documented Windows functionality. macOS remains experimental; a separate clean physical computer, Ideogram field reading, and naturally scheduled notifications retain their existing validation limits. Windows binaries are unsigned. No generation, purchase or automatic use of reset credits is involved.

## 简体中文

本 Windows 正式稳定版将 0.4.5-preview.2 中已验收的功能转为稳定发布。运行功能不变，更新版本号及当前发布说明。

- 小仪表尺寸与布局保持；显示余量 ≤20% 时数字和对应圆弧变为琥珀黄，≤10% 时变红。各周期独立判断，恢复额度后回到原色。
- 首次引导支持选择平台、连接、可选会员备注、中断后继续，并保留主动隐藏的平台选择。
- Runway、Recraft 使用各自的官方浏览器 OAuth，MiniMax 国际站使用 Subscription Key 查询。三条路径均已完成真实只读查询、本机加密保存及安装版重启后的刷新，无需 Codex CLI、Agent Relay 或 Python；其他平台保留已说明的依赖。
- 升级保留原设置、历史记录 ID、日期和浏览器配对。凭据与账号数据不进入分发包；MiniMax 的 Key 绑定不等于个人或团队身份已核验。

验证包括 262 项自动检查、隔离生产界面与主进程检查、包内首次使用和旧配置检查、产物与源码比对，以及实际 Windows 升级。从本 Release 下载安装器或便携 ZIP，可用 `SHA256SUMS.txt` 和 `SOURCE_VERSION.json` 核对文件完整性与源码版本。保留旧安装器和本机配置备份可供回退。

正式支持范围是文档所述 Windows 功能。Mac 仍为实验支持；另一台干净实体电脑、Ideogram 现场读取及自然未来通知保留原有待验边界。Windows 文件未代码签名。不涉及生成、购买或自动消耗重置卡。
