# 0.3.12 — Provider readers and membership forecasts

- Adds fixed read-only adapters for Runway's existing Codex app connection, Kling's existing CLI, and Recraft's official hosted subscription MCP. A usable original connection is required; Gauge does not add a login flow or store provider sessions.
- Runway keeps plan and purchased credits separate and scopes readings to a connection and workspace. Switching workspaces retires the old workspace's bound dates, including after later failures and restarts.
- Known platforms can receive editable monthly forecasts before a balance connection exists. Forecasts never create balances or confirm a credit grant, and remain outside the creative back until a current balance is known.
- Existing expiry priority, daily-gift suppression and original Codex badge behavior remain intact.

**Live validation limit:** The Runway balance tool works in the connected host, but standalone automatic tool discovery/dispatch did not succeed in the local test environment (discovery 403, runtime timeout / unknown tool). Its automatic reader is not verified live. Kling requires renewal of its existing CLI login; Recraft requires an existing authorized official MCP. Synthetic native checks establish UI/refresh/error handling only. Windows builds are unsigned; Mac has not been device-tested.
