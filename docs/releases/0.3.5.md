# 0.3.5: First-use guidance and date entry

New users can see discovered local tools, available automatic-query paths and successfully read balances in one skippable guide. Reopen **Quick start** from the credit-center header. Existing installations keep their workflow without an automatic onboarding popup.

**Set dates** is available from the guide and each non-Codex tool's Details. Enter an expiry date, a monthly subscription grant day, or both. No private configuration file or website login is required. Verified accounts/pools can be selected explicitly; unverified sources use a separately named user record. Monthly forecasts require a monthly subscription type, preserve day 31 across short months, and never confirm arrival or overwrite balances.

Entries appear in the overview and calendar, support editing/deletion and individual reminders, and persist locally. Changing the bound account or pool gives reminders a separate receipt scope; old account bindings do not carry into a new login. Date-only MCP events expose `at: null`. Storage failure preserves old dates; guidance remains skippable even when its completion state cannot be saved.

No new provider login, browser cookie access, model requests or cloud monitoring. Original Codex badge and settings remain separate. Windows packages are unsigned; Mac and natural future notification delivery still need field testing. See [first use](../GETTING_STARTED.md) and [privacy verification](../PRIVACY_VERIFICATION.md).

## 中文

首次使用引导集中展示发现的本机工具、具备的自动查询入口和已读到的余额。可以跳过，也能从额度中心顶部“使用引导”重新打开；旧安装升级不自动弹出。

引导和各非 Codex 工具详情均可“填写日期”：直接填一次到期日、订阅积分每月预计发放日，或两者都填，无需改配置文件、无需网页登录。已有已核实账号 / 积分池可明确选择；身份未知的来源单独填写账号别名。月度预计须确认是按月订阅，短月取月底，之后恢复原日号；预计不代表到账，也不改写余额。

日期保存在本机，进入总览与日历，可修改、删除及单独关闭提醒。切换绑定账号或积分池分别去重，旧账号绑定不套到新登录。MCP 只提供日期、不编造时刻。保存失败保留旧记录；引导状态无法保存时，本次仍可跳过进入看板。

原 Codex 小仪表与偏好保留，不新增平台登录、Cookie 读取、模型请求或云端监控。安装包仍未签名；Mac 和自然未来通知送达仍待实测。参见[首次使用教程](../GETTING_STARTED.zh-CN.md)和[分发隐私核对](../PRIVACY_VERIFICATION.md)。
