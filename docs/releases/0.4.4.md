# 0.4.4 — TapNow on-demand sync

Windows live validation passed: automatic home-page reading, history retained after closing, and a new reading after reopening.

TapNow now discovers normally opened, permitted home tabs. Opening or returning to the home page requests a read; existing five-minute sampling continues while it is open. Gauge no longer reloads TapNow, opens a separate background tab or wakes discarded pages. Close the page after use; the credit center retains the last amount and time as unconfirmed.

The account menu is restored after sampling unless the user takes over. Activity requests are throttled and respect automatic-query pause. Existing pairing, site permissions, original Codex gauge and Ideogram behavior are preserved. Reload the existing browser extension once after updating Gauge.

No MCP balance query or desktop-client balance source is available in this version. Page data remains account-unverified and may lag the provider’s server. Only the normal home page is supported, not working canvases. 210 automated checks and 18 packaged empty-profile checks passed. Live Windows readings matched the credit center and creative back; closing retained the last amount and time, and reopening resumed automatic reads. Mac and Ideogram remain unverified in the field.
