# 0.4.0 preview — Optional browser balance reader

TapNow and Ideogram can use an optional locally loaded Chrome/Edge component when their official member MCP provides no balance query. Open **All tools → View → Connect page balance**. The user loads the component, pairs with Gauge and selects a full visible balance and persistent account/team marker. [Setup](../BROWSER_CONNECTION.md).

The component is off by default, requests each provider's site permission separately and refreshes only its own dedicated tabs. It copies no provider cookies or sessions. The local bridge validates the extension origin, encrypted pairing key and per-command freshness. Re-pairing revokes the old key. Missing, disconnected and changed readings stay unconfirmed; a valid zero remains used up. Page readings are explicitly account-unverified and do not confirm grants or inherit verified dates. Existing date forecasts and original Codex/card-click behavior remain intact.

Validation: 191 automated checks; 73 source-native and 73 packaged-native fixture checks; 18 isolated empty-profile checks. The installer and portable ZIP payloads match, including the browser component. Installed Windows checks preserve the original gauge, card clicks, preferences and independent dates. Fixtures use synthetic data. **A real provider browser reading and an unattended five-minute provider refresh still need field validation. This preview must not be described as a confirmed live TapNow/Ideogram connection.** Mac remains unverified. Browser-store distribution is not provided.

## 简体中文

TapNow、Ideogram 的官方会员 MCP 没有余额查询工具时，可以选择本地加载的 Chrome / Edge 组件。入口：**全部工具 → 查看 → 连接网页余额**。用户加载组件、本机配对，再点选完整余额数字与长期显示的账户 / 团队标识。[操作教程](../BROWSER_CONNECTION.zh-CN.md)。

组件默认关闭，网站权限分开确认，只刷新自己创建的专用标签页，不复制平台 Cookie 或登录会话。本机连接校验扩展来源、加密配对密钥和请求时效；重新配对使旧连接失效。缺失、断开和位置变化保持待确认，确实读到零才算用尽。网页余额明确标记账号待核实，不确认发放到账、不继承已验证账号日期。原日期预计、小仪表及单击翻面继续保留。

191 项自动检查、源码与包内各 73 项原生模拟检查、18 项空白用户隔离检查通过；安装版与 ZIP 内容一致，含浏览器组件。Windows 安装后原小仪表、翻面、设置和独立日期保留。**真实平台读数及完整五分钟自动刷新仍待现场验证，本预览不能称为 TapNow / Ideogram 已实际接通。** Mac 未实测，组件尚未上架浏览器商店。
