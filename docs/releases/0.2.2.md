## Codex Gauge 0.2.2

- Restores the small gauge when Windows leaves it behind the active Codex window. Window order recovers automatically while the existing visibility rules apply. Keep on top preferences and keyboard focus are preserved.
- Repairs retained-notification activation with a stable Windows activator identity and a global callback. Credit-expiry, scheduled-reset and public-announcement reminders share one delivery path.
- Confirms deduplication only after the native show acknowledgement. Explicit send failures retain a maximum of three attempts across restarts, with bounded backoff. Uncertain delivery stops automatic resend; English/Chinese notices explain failures and retry exhaustion.
- Preserves preferences and legacy reminder records. No model requests, automatic quota spending or credit use.

45 automated checks, the Windows native build and read-only quota smoke passed. Separate Windows testing confirmed native toast delivery, retained-notification opening after sender restart, and real badge ordering recovery. Full cold-launch clicking, natural quota events, real sleep/sign-in and Mac remain field-validation gaps. See [verification](https://github.com/Akenaiai/codex-gauge/blob/main/docs/VERIFICATION.md) and [Windows notification acceptance](https://github.com/Akenaiai/codex-gauge/blob/main/docs/NOTIFICATIONS.md).

Windows x64: setup executable and portable ZIP, with SHA256SUMS.txt and SOURCE_VERSION.json. The Windows build is not Authenticode-signed. Older 0.2.1 notifications may retain their previous activation identity; migration is not guaranteed.
