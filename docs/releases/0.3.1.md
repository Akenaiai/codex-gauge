# 0.3.1 — Connected quota queries and sourced renewal rules

Tavily can now read remaining plan quota through its official usage API, reusing an active local MCP credential. Its monthly renewal is shown as a date only: Tavily specifies the first day of the month but no exact time or timezone. Reminders ask the user to verify the balance instead of announcing an unobserved grant.

The credit center adds an encrypted connection dialog for Firecrawl, Tavily and DeepSeek. It verifies a read-only query before saving a key with system encryption. Old in-flight queries cannot overwrite a new connection; failed persistence rolls back the prior credential and account view. Replacing a host snapshot is an explicit account/workspace choice, preserving independent snapshots.

Official expiry/renewal rules and source links are available for supported platforms. Firecrawl's monthly billing period can identify an expected plan-credit reset, while the combined balance's expiry stays unknown. A policy-derived cycle or balance increase is never promoted to a confirmed renewal. Date-only schedules remain date-only in the UI and MCP output.

Firecrawl requires an independently usable existing API credential for unattended refresh. A host-only plugin connection or a historical snapshot does not prove such access. The prior Codex badge, settings and reminder controls remain in place. No model calls, generation, purchases, or card redemption are added.

## 简体中文

新增 Tavily 自动额度查询，可沿用已启用的本机 MCP 配置。每月1日的恢复按日期展示，明确标记官方未说明具体时刻和时区。

Firecrawl、Tavily、DeepSeek 新增“验证并加密保存”连接入口。验证只读查询后才保存凭据；更换账号时隔离旧请求，保存失败恢复原连接，替换某条快照须确认同一账号或工作区。

各平台到期与恢复规则附官方来源。Firecrawl 账期与官方规则可推导套餐积分的预计重置时间，合计余额仍不猜测到期日；推算或余额增加不冒充已到账。原 Codex 小仪表与设置保留。

Firecrawl 当前账号若只有宿主插件授权，仍需可独立使用的既有 API 凭据，不能把快照或连接入口完成写成自动刷新实连完成。自然提醒送达及 Mac 仍保留原验证边界。
