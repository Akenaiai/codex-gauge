# 刻度首次使用教程

[English](GETTING_STARTED.md) · [返回首页](../README.zh-CN.md) · [下载安装包](https://github.com/Akenaiai/codex-gauge/releases/latest)

适用于 Windows 0.3.4。刻度保留原 Codex 小仪表，并提供统一的 AI 额度中心。**不需要注册刻度账号，也不需要在刻度里额外登录各个平台。** 查询沿用你自己电脑上的已有连接。尚未登录的工具，需要在它原来的客户端或 CLI 中完成登录；也可以先跳过。

## 1. 安装并打开

1. 打开上方发布页，在 **Assets** 下载 `Codex.Gauge.Setup.0.3.4.exe`。需要免安装运行时选 `Codex.Gauge-0.3.4-win.zip`，完整解压后运行其中的 `Codex Gauge.exe`。后续版本以发布页文件名为准。GitHub 的 **Source code** ZIP 是源码，需要开发环境才能运行。
2. 系统要求是 Windows 10/11 x64。安装包已包含桌面运行环境，无需另装 Node.js；可选的 Agent Relay 查询需要另外安装该工具及 Python。
3. 当前安装包没有 Windows 代码签名。可将下载文件右键复制路径，在 PowerShell 运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '下载文件的完整路径'`，与同一发布页的 `SHA256SUMS.txt` 比较。这只能验证文件是否一致，不等于代码签名；不要关闭系统保护。
4. 运行刻度。从任务栏通知区域的刻度图标打开 **额度中心 · 全部 AI 工具**；图标可能收在隐藏图标菜单中。已有 Codex 小面板也有进入额度中心的按钮。

原 Codex 小仪表需要 Codex 桌面客户端和已经安装、登录的[官方 Codex CLI](https://github.com/openai/codex)。登录由官方工具管理，刻度无需额外的 Codex API Key。打开 Codex 后小仪表会尝试跟随头像；没有显示时先从托盘打开。Mac 仅有未实机验证的源码悬浮预览，没有对应的已验证安装包。

## 2. 第一次看什么

1. 在 **全部工具** 查看发现依据，例如 CLI、MCP 配置、插件或仅安装缓存。目录只说明本机发现了什么，不代表每项都已登录或有余额查询接口。
2. 对已有查询适配的工具，打开 **查看 / 详情 → 刷新**，核对账户、来源和读取时间。缺少连接时按下方表格处理。没有适配的工具可用 **补充记录**，记录会标为“本人记录”。
3. 回到 **额度总览**，先用四个筛选判断要用什么。

| 筛选 | 怎么理解 |
| --- | --- |
| 有额度 | 当前有效读数显示仍有可用额度；不同平台单位、账号分别看 |
| 已用尽 | 当前有效读数确认已用尽；未知数据不会当作零 |
| 临期 / 快重置 | 7 天内到期或 2 天内重置，可与前两种状态重叠；重置卡到期会单独注明 |
| 待确认 | 未读取、失败、过旧或周期已过，需要刷新核实 |

点击 **详情 → 日期与来源** 看完整积分池和读取时间；在 **到期与恢复** 看日历。不同账号的余额不会自动合并，网页记录也不会自动认作 API 查询的同一个账号。刚装好的刻度不带开发者的账户、余额或日期规则；没有发现受支持的本机来源时，列表可能为空。截图中的数据均为合成示例。

## 3. 会读取哪些本机连接

CLI 是命令行工具，MCP 是供 AI 客户端调用的工具连接，插件是客户端扩展。同一个平台可以同时有几种接入方式；看到多个入口不代表拥有多份额度。

读取范围是**运行刻度的当前系统用户环境**：常见客户端配置、已知工具安装位置和当前进程环境变量。它不做全盘扫描，不主动查找其他系统用户、其他电脑或全部云端账号。自定义位置、浏览器专用服务、宿主托管 OAuth 连接可能无法自动发现或复用。

| 本机来源 | 用于什么 |
| --- | --- |
| Codex、Claude Code / Desktop、Cursor、Gemini CLI、Qwen Code、OpenCode、Windsurf 常见配置 | 提取 MCP / 插件名称、启用状态等目录信息；被发现不代表已登录或能查额度 |
| PATH 与常见用户工具目录 | 查找已知 CLI，不执行任意发现的 MCP 启动命令 |
| `~/.codex/skills`、`~/.agents/skills`、Codex 插件缓存 | 判断相关工具的安装线索；缓存不代表启用，也不代表连接可用 |
| 当前进程的对应 API 环境变量、对应且已启用的 MCP 配置 | 为已支持的 API 适配读取凭据；OpenCode / Windsurf 当前仅参与目录发现，不复用其 API Key |
| 当前用户可选的本机加密凭据和私人导入文件 | 读取自己保存的 API 连接、宿主快照或日期记录；安装包不附带这些数据 |

已支持的自动余额查询如下。其他工具会保留在目录中，不能保证每个都有自动查询。

| 工具 | 查询所需连接 | 日期边界 |
| --- | --- | --- |
| Codex | 已登录的官方 CLI，本机 app-server 只读查询 | 只展示接口实际返回的窗口、重置及卡片日期 |
| 小云雀、即梦 | 原工具已安装且已登录的原生 CLI | 当前余额响应没有积分到期 / 发放日 |
| Lovart | Codex 中已有且可用的 Lovart MCP 连接 | 仅固定余额工具，当前响应不提供账号身份和日期 |
| Kimi、MiniMax、ZCode | 另行安装的 Agent Relay 与 Python、对应已有连接 | 以接口返回为准；缺少伴随工具时不会自动安装或派任务 |
| Firecrawl、Tavily、DeepSeek | 对应 API 凭据 | 接口日期与规则推导分开，余额不一定有到期日 |

Firecrawl、Tavily、DeepSeek 可以复用当前进程的 `FIRECRAWL_API_KEY`、`TAVILY_API_KEY`、`DEEPSEEK_API_KEY`，或 Codex / Cursor / Claude / Gemini / Qwen 的对应已启用 MCP 配置中的变量。Windows 的 Firecrawl 和 DeepSeek 查询还支持当前用户 `~/.codex/private/credentials/<provider>-api-key.dpapi`。这些是可选读取路径，不要求创建这些文件。

没有已有 API 连接时，可自愿使用 **详情 → 连接查询** 输入自己的 API Key。刻度先验证只读查询，再用本机系统加密保存；这不是平台账号登录，也不会创建 Key、购买套餐或扩大权限。也可以不填写，保留待确认状态。不要把 Key、Cookie、配置文件或真实额度截图发到公开 Issue。

## 4. 哪些日期是实查，哪些是预计

**每个日期都要看来源和核对时间。余额刷新成功，不代表网页日期也更新了。**

| 来源 / 标记 | 能说明什么 | 刷新方式 |
| --- | --- | --- |
| 自动查询中的日期 | 上次接口实际返回的该账户日期；未来恢复仍需到时查询 | 随支持的余额接口重新读取；失败保留旧读数并标记 |
| 网页账户、核对于、非实时 | 一次真实网页核对的历史记录，可能已变化 | 由用户在自己的浏览器核实并更新私人导入；刻度不会登录网页或自动抓取 |
| 官方规则 / 依官方规则 | 按公开规则展示有效期或推导恢复日，不是到账凭证 | 可在详情查看规则来源和核对日期；规则说明不是实时政策服务 |
| 本人确认 | 用户填写的一次日期，准确性由填写者核对 | 详情中用“补充日期”修改；到时提醒核实 |
| 按月度同日规则预计、未确认到账 | 用户设置的每月预计发放日 | 随日历推进，支持修改或关闭；不会自动认定到账 |
| 日期未提供 / 日期未展示 | 当前来源没有足够信息 | 保持未知；不拿会员截止日或账单日代替 |

只有日期就不补具体时刻；页面未说明时区时保持未知。**积分到期、额度重置、会员到期、账期结束是不同事件。** 没有到期日也不代表永久有效，只有来源明确说明时才显示永久有效。

### 设置每月预计发放

当前 0.3.4 的入口只出现在小云雀、即梦、Lovart 的合格月度 / 订阅**网页日期记录**中：**详情 → 日期记录与预计发放 → 设置月度发放日 / 修改**。新安装没有这些私人记录，因此可能看不到这个按钮。建立记录属于[进阶的私人文件导入](CREDIT_CENTER.md#account-page-date-observations)，当前没有通用的图形化网页记录创建入口。普通使用者可以先在已有积分池中用 **补充日期** 保存一次已确认日期。

有合格记录后，选择上次发放日或积分失效日，再确认通常每月几号发放。例如某月 12 日发放，预计下月 12 日；选择失效日时，可把该日作为下期预计发放日。31 日遇到短月取当月最后一天，之后仍保留 31 日。这里的示例不是预置账户数据。

只给实际按月发放的订阅池设置规则。永久余额、充值余额、每日领取积分不套用月度规则。预计不继承失效的钟表时刻，也不因总余额增加而宣称到账。原日期记录保持历史，改规则不会把它变成实时日期。

## 5. 开启查询与提醒

在额度中心 **查询与提醒设置** 开启 **运行时自动查询** 和 **到期与恢复提醒**。自动查询默认每五分钟进行，手动刷新可随时使用。原 Codex 小仪表通常每分钟读取，其提醒仍由原仪表设置控制。

新平台已知到期可在 7 / 3 / 1 天提醒；符合条件的周期额度可在重置前 2 小时 / 1 小时提醒。月度预计会在临近、当日及有限的逾期阶段提醒核实，**日期到了不会显示成已到账**。提醒按来源、账号及阶段去重；实际送达仍受 Windows 通知设置影响。

退出刻度、电脑休眠或关机期间暂停查询，重新运行后补查，不能保证补发每一条错过的通知。需要随 Codex 打开时，可在 Windows 安装版的原仪表设置启用 **随 Codex 启动**；新用户默认关闭，可随时关闭并移除相应当前用户任务。没有云端代查或跨夜服务。

## 6. 常见情况

| 情况 | 处理 |
| --- | --- |
| 提示“需要登录” | 在对应工具原来的官方客户端 / CLI 登录，然后回刻度刷新；无需在刻度输入密码或验证码 |
| 只看到插件缓存 | 先确认原宿主是否启用该连接，以及刻度是否有该平台适配 |
| 刚配置的工具没有出现 | 在“查询与提醒设置”点“重新梳理工具”；环境变量变更后重启刻度 |
| Lovart 有余额但没有日期 | 当前 MCP 不返回日期或账户身份；网页记录需独立核对，不能自动绑定 |
| API 刷新后网页日期没变 | 属于正常边界，网页记录是上次核对的历史记录 |
| 恢复日期已到但余额未变 | 查看预计 / 规则标记，再刷新对应来源核实；可能有领取条件或平台延迟 |
| 查询失败或数据过旧 | 保留上次记录并标待确认，检查网络及原连接，稍后刷新；失败不会变成零余额 |

## 数据保存与开源范围

设置、工具清单、余额、私人日期及提醒回执保存在刻度的当前用户数据目录；Windows 通常为 `%APPDATA%/Codex Gauge`，启动环境虚拟化可能使实际目录不同。可选 Key 保存在本机系统加密的 `credit-secrets.json`，普通余额记录不含 Key。不要分享整个数据目录，也不要把它当作绿色 ZIP 的可分发附件。

刻度不读取浏览器 Cookie 或聊天档案，不提供平台网页登录，不自动生成作品、花积分、充值、用卡或发模型请求。受支持的 CLI / MCP 查询沿用客户端原有认证；API 查询会向对应平台发送认证请求。原仪表还可访问匿名 AIHOT 公告，手动检查更新会访问 GitHub；没有刻度账号服务器或遥测。详见[数据与限制](../README.zh-CN.md#数据和当前边界)、[安全说明](../SECURITY.md)和[本次分发隐私核对](PRIVACY_VERIFICATION.md)。MIT 许可覆盖项目代码，第三方工具、服务和数据仍遵循各自规则。
