# 创作积分临期提醒

[English](CREATIVE_EXPIRY.md)

Windows 0.4.7 已提供此功能。验证范围和仍待现场验证的项目见[发布说明](releases/0.4.7.md)。

创作背面将非每日赠送、7 天内到期且值得提醒的积分置顶，按到期时间从近到远排列。判断依据是即将失效的积分池金额，不是账户总余额。**100 积分及以下**保留普通余额和日期，不显示临期角标、不因到期置顶，也不发送到期通知。

在创作平台卡片的**提醒设置**中，可以单独修改该平台的忽略线，包含所填数值。默认 100，填 0 表示有正积分就可提醒。设置重启后保留，不影响其他平台和 Codex。忽略线仅用于积分；百分比、次数保留各自单位，不换算成积分。临期金额未知时，只保留普通日期信息。

| 距离到期 | 超过忽略线的积分如何显示 |
| --- | --- |
| 超过 7 天 | 普通余额和日期 |
| 7 天内 | 琥珀色标签、自动置顶，暂不发送系统通知 |
| 3 天内 | 加强琥珀色提示，静默通知一次 |
| 24 小时内 | 到期标签标红，最后静默通知一次 |
| 降到忽略线及以下 | 恢复普通文字，撤去临期强调和后续通知 |

只有日期的记录按天显示，最后提醒发生在记录当天，不编造具体到期时刻或时区。网页记录、本人填写日期继续注明需要核实。原有账号、数据新鲜度、通知开关及每日赠送静音规则仍适用。通知回执不会因重启清空。

**本批不再提醒**可撤去这批积分的临期强调和后续通知，重启后仍生效；只针对对应账号、积分池和到期日。其他积分池及后续批次仍可提醒。余额、日期继续显示，Codex 提醒独立保留。

小仪表保留 Codex 额度读数和重置标记，另用独立的图片图标表示创作积分临期，点击直接打开创作背面。翻面入口显示临期平台数量。系统通知明确标注来源，创作积分到期使用独立通知分组和点击目标。普通关闭后重开仍默认 Codex 正面。

设置和静音回执保存在原有本地积分中心文件中。没有新增服务、平台登录、生成请求或分析追踪。自动检查和隔离 Windows 检查不代表自然未来通知送达或 Mac 行为已经验证。
